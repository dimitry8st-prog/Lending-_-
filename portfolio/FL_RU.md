# Готовое описание проекта для FL.ru

## Название проекта

Разработка адаптивного лендинга для клуба единоборств

## Краткое описание

Современный одностраничный сайт спортивного клуба с направлениями, тренерами, расписанием, филиалами, абонементами и формой записи на пробную тренировку.

## Подробное описание

Разработал демонстрационный коммерческий лендинг для клуба самбо, боевого самбо и джиу-джитсу.

Главная цель проекта — представить спортивный клуб, сформировать доверие и привести посетителя к записи на бесплатное пробное занятие. Структура сайта построена как последовательная воронка: оффер, информация о клубе, направления, тренеры, расписание, цены, филиалы и форма заявки.

Выполненные работы:

- проектирование структуры лендинга;
- разработка визуальной концепции;
- адаптивная вёрстка;
- мобильное меню и навигация;
- компоненты направлений, тренеров, расписания и абонементов;
- форма записи и проверка обязательных полей;
- базовые SEO-метаданные;
- подготовка к подключению CRM, Telegram, email и веб-аналитики;
- настройка сборки и автоматических проверок.

Стек: React 19, TypeScript, Next.js/Vinext, Vite, CSS, Cloudflare Workers.

Проект можно адаптировать под фитнес-клуб, спортивную школу, секцию, тренера или локальный сервисный бизнес.

## Роль в проекте

Структура, UX, визуальная концепция, frontend-разработка, адаптивность, форма заявки, SEO-подготовка и техническая документация.
