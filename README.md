# Makarov Team

Адаптивный одностраничный сайт клуба единоборств для детей от 4 лет и взрослых.

**Проект №4 в портфолио Степанова Дмитрия.**

Демонстрация: https://makarov-team.ketwolsheb.chatgpt.site

## О проекте

Сайт представляет направления клуба, тренеров, расписание, абонементы, достижения и филиалы. Основная цель — помочь родителям и взрослым спортсменам быстро выбрать программу и записаться на пробную тренировку.

Дизайн выполнен в спортивной стилистике с использованием фирменной палитры Makarov Team: красного, белого и тёмно-синего цветов.

## Реализовано

- адаптивная вёрстка для компьютеров, планшетов и телефонов;
- фиксированная навигация и мобильное меню;
- главный экран с призывом к записи;
- блоки «О клубе», «Направления», «Тренеры» и «Достижения»;
- расписание тренировок;
- карточки абонементов;
- галерея тренировок и соревнований;
- карточки филиалов в Одинцове и Переделкино Ближнем;
- форма пробной записи с обязательными полями и проверкой;
- плавная навигация и интерактивные состояния элементов;
- базовые SEO-метаданные.

## Технологии

- React 19
- TypeScript
- Vinext / Vite
- CSS
- Cloudflare Workers

## Локальный запуск

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

После запуска откройте адрес, показанный в терминале.

## Проверка и сборка

```bash
npm run lint
npm test
npm run build
```

## Что нужно заменить перед коммерческим запуском

В демонстрационной версии используются места для материалов, которые должен подтвердить заказчик:

- оригинальный логотип;
- фотографии тренеров, залов и соревнований;
- регалии тренеров;
- точные адреса филиалов;
- телефон и ссылки на социальные сети;
- актуальные расписание и цены;
- ссылки на Яндекс Карты и виджет отзывов;
- адрес обработчика формы или подключение CRM/Telegram.

## Структура

```text
app/
  page.tsx       — содержимое и компоненты лендинга
  globals.css    — стили и адаптивность
  layout.tsx     — метаданные и корневая разметка
public/          — статические материалы
worker/          — серверная точка входа
tests/           — автоматические проверки
```
