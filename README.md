## Зачем создан лендинг

Лендинг решает типовую задачу спортивной секции: **перевести интерес родителя или взрослого спортсмена в заявку на пробную тренировку**.

Без понятного сайта клубу сложно:

- быстро объяснить, чем отличаются самбо, боевое самбо и джиу-джитсу;
- снять страх «не тот возраст / не та подготовка»;
- показать филиалы, расписание и формат старта;
- собрать контакты без звонка администратору в неудобное время.

Сайт собирает воронку в одном экране пути:

1. **Внимание** — сильный первый экран и фирменный визуал  
2. **Доверие** — о клубе, тренеры, жизнь секции  
3. **Выбор** — направления, расписание, филиалы, абонементы  
4. **Действие** — форма записи на бесплатную пробную тренировку  

Это демонстрационный коммерческий кейс: структуру, UX и адаптив можно быстро перенести на реального заказчика после замены контента, фото и обработчика заявок.

## Для кого создан

| Аудитория | Что получает на сайте |
|---|---|
| **Родители детей от 4 лет** | Понятный старт «с нуля», безопасность, возраст групп, запись ребёнка |
| **Подростки и взрослые** | Боевое самбо и джиу-джитсу, расписание вечерних групп |
| **Владелец / администратор клуба** | Готовая цифровая визитка для рекламы, сарафана и локального SEO |
| **Заказчик лендинга (B2B)** | Шаблон конверсионного сайта спортивной школы под замену бренда |

**Не для кого:** это не маркетплейс, не личный кабинет ученика и не полноценный CRM — фокус именно на презентации клуба и сборе лидов.

## Цель проекта

Сделать **понятную и энергичную цифровую визитку** клуба единоборств, которая:

- одинаково удобна на компьютере, планшете и телефоне;
- ведёт посетителя к одной главной цели — заявке на пробное занятие;
- выглядит спортивно и узнаваемо (красная / тёмно-синяя палитра, сильный hero);
- готова к подключению CRM, Telegram, карт, аналитики и реальных фото клуба.

## Что реализовано

- адаптивная вёрстка с fluid-типографикой и несколькими брейкпоинтами;
- фиксированная навигация и мобильное меню с CTA;
- главный экран с призывом к записи и фирменным визуалом;
- блоки «О клубе», «Направления», «Тренеры», «Расписание», «Абонементы»;
- медиа-блок жизни клуба и карточки филиалов;
- форма пробной записи с обязательными полями и проверкой;
- базовые SEO-метаданные;
- подготовка к Cloudflare Workers (Vinext / Vite).

## Локальный запуск

Требуется Node.js **22.13** или новее.

```bash
npm install
npm run dev
```

Откройте адрес из терминала (обычно `http://localhost:5173/`).

### Проверка и сборка

```bash
npm run lint
npm test
npm run build
```

## Что заменить перед коммерческим запуском

В демоверсии нейтральные имена и филиалы. Перед продакшеном нужно подтвердить у заказчика:

- название бренда и оригинальный логотип;
- фото тренеров, залов и соревнований;
- регалии и стаж тренеров;
- точные адреса филиалов;
- телефон и соцсети;
- актуальное расписание и цены;
- Яндекс Карты и виджет отзывов;
- обработчик формы (CRM / Telegram / email);
- политику персональных данных.

## Структура

```text
app/
  page.tsx       — содержимое и компоненты лендинга
  globals.css    — стили и адаптивность
  layout.tsx     — метаданные и корневая разметка
public/          — статические материалы (в т.ч. hero-изображение)
worker/          — серверная точка входа
tests/           — автоматические проверки
```
