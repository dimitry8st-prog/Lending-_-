# Force Team — лендинг клуба единоборств

Адаптивный одностраничный сайт для клуба самбо, боевого самбо и джиу-джитсу. Проект показывает полный путь посетителя: от знакомства с направлениями и тренерами до записи на бесплатную пробную тренировку.

## Задача проекта

Спортивному клубу нужен сайт, который быстро объясняет ценность занятий, вызывает доверие у родителей и взрослых спортсменов и переводит интерес в заявку.

Лендинг решает четыре задачи:

1. привлекает внимание сильным первым экраном;
2. знакомит с направлениями, тренерами и клубом;
3. помогает выбрать расписание, филиал и абонемент;
4. ведёт к записи на пробную тренировку.

Проект создан как адаптируемая основа: бренд, фотографии, тексты, цены и обработчик формы можно заменить под конкретный клуб.

## Целевая аудитория

| Аудитория | Польза сайта |
|---|---|
| Родители детей от 4 лет | Возраст групп, безопасный старт, знакомство с тренерами |
| Подростки и взрослые | Направления, расписание и условия занятий |
| Владелец клуба | Цифровая визитка для рекламы, локального SEO и сбора заявок |
| Заказчик лендинга | Готовая структура коммерческого сайта спортивной секции |

## Что реализовано

- адаптивный интерфейс для компьютеров, планшетов и телефонов;
- фиксированная навигация и мобильное меню;
- главный экран с оффером и призывом к действию;
- блоки о клубе, направлениях, тренерах, расписании и абонементах;
- карточки филиалов и медиаблок;
- форма записи с обязательными полями и проверкой;
- базовые SEO-метаданные;
- подготовка к подключению CRM, Telegram, email и аналитики;
- архитектура для развёртывания на Cloudflare Workers.

## Технологии

- React 19
- TypeScript
- Next.js / Vinext / Vite
- CSS и Tailwind PostCSS
- Cloudflare Workers
- ESLint и автоматические проверки

## Локальный запуск

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

Адрес локального сервера отображается в терминале, обычно `http://localhost:5173/`.

### Проверка и сборка

```bash
npm run lint
npm test
npm run build
```

## Структура проекта

```text
app/
  page.tsx       — содержимое и компоненты лендинга
  globals.css    — стили и адаптивность
  layout.tsx     — метаданные и корневая разметка
public/          — изображения и статические материалы
worker/          — серверная точка входа
tests/           — автоматические проверки
```

## Перед коммерческим запуском

Заказчику необходимо предоставить:

- название, логотип и фирменные цвета;
- фотографии тренеров, залов и соревнований;
- регалии тренеров;
- адреса, телефон и ссылки на социальные сети;
- расписание и цены;
- реквизиты для подключения формы заявок;
- текст политики обработки персональных данных.
